# so the blob keeps supplying the retail table bytes. splat re-emits a
# `.word .L<addr>` for any entry whose target address has a known label;
# scripts/apply_jtbl_extern_words.py (run by resplat.sh after every
# split) converts each listed entry back to its raw retail word.

# Format: <blob .s path relative to repo root> <label-addr hex>
# (the entry's own bytes are recovered from the line's splat comment;
# `.word .L<addr>` jump-table entries and `.word $LEH_<addr>` EH-region
# boundaries are both handled — the latter for C++ TUs that strip their
# own emitted .gcc_except_table, added when the iostream cluster lands.)
